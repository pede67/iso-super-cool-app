# Electric Cars Database Plugin

This WordPress plugin provides a searchable database of electric cars with customizable comparison parameters. Cars can be organized by brand, model and variant and include a featured image.

## Features
- Custom post type `Electric Car` with image support.
- Taxonomies for **Brand**, **Model** and **Variant** so cars can be sorted and filtered.
- Admin page to create, update and delete custom parameters.
- Meta box for entering parameter values for each car.
- Shortcode `[electric_cars]` to display a searchable and comparable list of cars.

## Installation
1. Copy the `electric-cars-plugin` directory to your WordPress `wp-content/plugins` directory.
2. Activate **Electric Cars Database** from the Plugins menu.
3. Use the *Electric Cars* menu in the admin dashboard to define parameters and add cars.
4. Place the shortcode `[electric_cars]` on any page or post to show the search and comparison table.
